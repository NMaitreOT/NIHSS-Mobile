NIHSS Mobile V3

INSTALLABLE iPhone/iPad PWA
1. Upload the contents of this folder to an HTTPS-enabled web host. Keep the filenames together.
2. Open index.html in Safari on the iPhone/iPad.
3. Tap Share > Add to Home Screen.
4. Open the installed app once while online so the service worker can cache all files. It is then designed to work offline.

STANDALONE VERSION
A separate NIHSS_Mobile_V3_Standalone.html file embeds all stimulus images into one file. It is useful for local storage/testing, but Apple does not install a local file:// HTML document as a true PWA.

PRIVACY
The app intentionally has no patient identifier fields and does not send or persist assessment responses. Theme preference may be stored locally.

CLINICAL USE
Validate the app and its content through the appropriate clinical/governance process before production deployment.
