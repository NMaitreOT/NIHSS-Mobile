NIH Stroke Scale

Mobile V3 • guided scoring • standardized stimuli

Use on iPhone or iPad

Apple Safari
  1. For the installable version, place the PWA folder on an HTTPS website and open index.html in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Launch NIHSS from the Home Screen once while online. The app then caches its files for offline use.

Single-file version: the standalone HTML includes all stimulus images inside the file and can be retained locally, but iOS does not treat a local HTML file as an installed PWA.

Administration: Complete the standardized examination in order and score observed performance. This calculator supports scoring; it does not replace NIHSS training, stroke evaluation, imaging, or treatment protocols. No patient identifiers are requested.
